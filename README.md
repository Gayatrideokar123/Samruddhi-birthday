# Samruddhi — Personal Pinterest-Style Birthday Website 💗

This version contains NO stock, cake, flower or decoration photos. The gallery is made for your own photos.

## Add your own photos permanently
1. Open the extracted project folder.
2. Open the `images` folder.
3. Copy your photos into it.
4. Rename them exactly `photo-1.jpg`, `photo-2.jpg`, ... `photo-7.jpg`.
5. Refresh `index.html` in your browser. Your photos will appear in the Pinterest-style gallery.

For this permanent folder method, use JPG/JPEG images. If your photo is PNG/WEBP, convert it to JPG first, or use the preview uploader described below.

## Preview photos without renaming
On the Memories page, click **Choose our photos** and select up to seven image files (JPG, JPEG, PNG, WEBP, etc.). They appear immediately in the browser as a preview. To keep them after closing the browser, copy JPG versions into `images` using the filenames above.

## Run in VS Code / Windows
1. Extract the ZIP.
2. Open the `Samruddhi_Pinterest_Style_Birthday` folder in VS Code.
3. Open `index.html` in a browser, or right-click it and choose **Open with Live Server**.
4. Click the music button to play the new original instrumental: a warm, cheerful acoustic-guitar melody with soft strings and a light flute line. It has a flowing, uplifting feel without piano, loud drums or repetitive electronic beats.

## Project files
- `index.html` — website structure and birthday messages
- `style.css` — Pinterest-inspired layout and styling
- `script.js` — navigation, photo preview, music and celebration effects
- `images/` — put your own photos here
- `music/hopeful-birthday-instrumental.mp3` — original calm birthday background music

No database, Node.js or installation is required.
